# SwiftUI Starter Architecture (MVVM + Services + Managers)

A reusable SwiftUI project template designed to speed up development with a clean and scalable architecture.

---

## 🚀 Features

* SwiftUI-based architecture
* MVVM pattern support
* Modular structure (Managers + Services + Models)
* Authentication module setup
* Reusable UI extensions
* Clean and scalable project structure

---

## 🧠 Architecture Overview

### 🔹 Views (SwiftUI)

Handles UI and user interaction using SwiftUI.

### 🔹 ViewModels

Manages state and business logic for views.

### 🔹 Services

Handles API calls and external communication.

### 🔹 Managers

Coordinates shared logic and app-level operations.

### 🔹 Models

Defines data structures across the app.
